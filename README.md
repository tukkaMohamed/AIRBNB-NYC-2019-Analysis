# Airbnb NYC 2019 — Data Analysis & Power BI Dashboard

## 📌 Project Overview
This project analyzes Airbnb listings in New York City using the 2019 dataset. The goal is to explore pricing patterns, listing distribution, neighborhood differences, and host and review activity through an interactive Power BI dashboard.

## 🎯 Project Objectives
- Analyze Airbnb listing prices and room types.
- Compare prices across NYC boroughs and neighborhoods.
- Explore listing distribution and market concentration.
- Investigate host listing patterns and guest review activity.
- Present key findings through interactive visualizations.

## 🛠️ Tools & Technologies
- Power BI Desktop
- Power Query for data cleaning and transformation
- DAX for measures and KPIs
- CSV dataset

## 📊 Dashboard Pages

### 1. Market Overview
An overview of the NYC Airbnb market, including key performance indicators, room type distribution, and listing distribution across boroughs.

### 2. Pricing Analysis
Explores price distributions, room type pricing differences, borough-level comparisons, and relationships between prices and listing supply.

### 3. Neighborhood Insights
Examines neighborhood-level listing concentration, median prices, and geographic patterns across NYC.

### 4. Reviews & Host Insights
Analyzes review activity, host listing counts, and neighborhoods receiving the highest total reviews.

## 📁 Repository Contents
- `AIRBNB NYC.PBIX` — Power BI dashboard file.
- `airbnb_nyc_cleaned.csv` — Cleaned dataset used in the analysis.
- `airbnb_nyc_outputs/` — Additional project outputs.

## 🚀 How to Explore
1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Explore the four report pages and interact with the available visuals.
